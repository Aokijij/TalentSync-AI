# Cómo mejorar los dos borradores incompletos

Los dos borradores se entregan con **38/100**. Los cambios propuestos permiten recorrer **38 → 64 → 80 → 93 → 100**. El número no basta para publicar: también deben cumplirse los requisitos obligatorios.

Abre **Mis vacantes → la oferta → Editar en Calidad de ofertas**. Guarda como borrador después de cada etapa. Las condiciones siguientes son propuestas para revisar antes de publicar.

## Desarrollador Backend Python · TalentSync

### 1. Condiciones claras: 38 → 64

- Salario fijo mensual: **4,000,000 COP**; máximo del rango: **4,400,000 COP**.
- Tipo de contrato: **Indefinido**. Dedicación: **Tiempo completo**.
- Modalidad: **Remoto**, con alcance en **Colombia**.
- Jornada: **lunes a viernes, de 08:00 a 17:00, con 60 minutos de descanso**.

En el texto del horario puedes usar: «Lunes a viernes, de 08:00 a 17:00, con una hora de descanso». Todavía faltan requisitos obligatorios, aunque la puntuación supere 60.

### 2. Responsabilidades y resultados: 64 → 80

**Responsabilidades**, texto para pegar:

Desarrollar y mantener la API de TalentSync con Python y FastAPI. Implementar validaciones, permisos y procesos transaccionales para perfiles, vacantes, aprendizaje y entrevistas. Revisar consultas SQL y migraciones, integrar fuentes de datos autorizadas y escribir pruebas de regresión. Documentar errores, contratos de la API y decisiones de arquitectura para facilitar el mantenimiento del equipo.

**Resultado esperado:** Entregar una mejora de la API con validación, permisos por rol y migración de datos cuando corresponda.

**Cómo se evalúa:** Revisión del cambio y ejecución de pruebas de autorización, persistencia y manejo de errores.

**Plazo:** 30 días.

### 3. Requisitos priorizados: 80 → 93

**Requisitos**, texto para pegar:

Fundamentos de Python, FastAPI, SQL y Git. Se aceptan proyectos personales o académicos con una API documentada, persistencia de datos y pruebas. pytest puede reforzarse durante el acompañamiento. Formación técnica, tecnológica o universitaria relacionada con desarrollo de software; se aceptan estudios en curso. No se exige experiencia laboral previa.

- Nivel del cargo: **Junior**.
- Experiencia mínima: **0 meses**; se aceptan proyectos como evidencia inicial.
- Formación: **Técnica**, aceptando estudios en curso.

Habilidades para registrar:

- **python**: esencial al ingreso, nivel básico.

- **fastapi**: esencial al ingreso, nivel básico.

- **sql**: esencial al ingreso, nivel básico.

- **git**: esencial al ingreso, nivel básico.

- **pytest**: deseable y aprendible durante el acompañamiento, nivel básico.

No marques una habilidad como esencial y aprendible al mismo tiempo.

### 4. Proceso de selección: 93 → 100

- Entrevistas previstas: **2**.
- Duración estimada del proceso: **14 días**.
- Compromiso de respuesta: **5 días**.
- Etapas: **Recibidas → En revisión → Entrevista → Contratados / No seleccionados**.

Preguntas de selección:

1. Describe un proyecto o actividad que se relacione con estas funciones y tu participación concreta.

2. ¿Cómo organizarías una primera tarea de este cargo y comunicarías un bloqueo al equipo?

Al terminar, revisa el informe de claridad y conserva el estado **Borrador** hasta decidir qué oferta utilizar.
